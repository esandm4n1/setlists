VERSION A

王道版

30〜40代に確実に刺さる現代ヒット+00年代懐メロ
構成の流れ: ゆっくり → かわいさ → たのしさ → はげしさ① → おちつき → セクシー → はげしさ② → クールダウン
使い方: 各曲の ▶ YouTube ボタンで検索結果(公式MVが最上位)に飛びます。BPMは目安です。
01ゆっくり / ウォームアップ
10分 ・ BPM 100-118
音楽的アプローチ レッスン開始の「世界観の提示」。BPMよりグルーヴ感とメロウさを優先。心拍を急に上げず、参加者がスタジオの空気に慣れる時間。Bruno Marsのレトロソウル系で「これから何かいいものが始まる」感を作るのが定番。

02かわいさ
12分 ・ BPM 113-134

03たのしさ
13分 ・ BPM 115-128
音楽的アプローチ ファンク・ディスコ・パーティー系で全員のノリを揃える。誰もが知ってる00〜10年代の鉄板ヒットを集中投入。つなぎはスムース重視(BPM・キー感を揃える)。
ここで「I Gotta Feeling」みたいな大合唱系を入れると、次の「はげしさ①」への熱量が確保される。

04はげしさ ① / エアロピーク
15分 ・ BPM 119-171 / 第一の山 🔥
音楽的アプローチ 心拍最大ゾーン。ロック・ハードEDM・パワフル女性アンセムで「攻める」セクション。つなぎはメリハリ重視:前セクションから明確にギアを上げる。ここでオリジナリティを出すと「あの先生のレッスンは違う」になる。
女性アンセム + ロックのミックスがハマる。「Run the World(Girls)」→「Bad Romance」→ロック系の流れが定番の盛り上がり。

05おちつき / 水分&リセット
8分 ・ BPM 96-105
音楽的アプローチ 第一の山のあと、必ずBPMを段階的に落とす(いきなり止めない)。つなぎはスムース絶対。怪我防止と次のセクシーへの心の準備。
歌い上げ系バラード寄りのミドルテンポで「整える時間」を演出。「Havana」を入れるとセクシーへの自然な橋渡しになる。

06セクシー
12分 ・ BPM 99-124

07はげしさ ② / ズンバ爆発
15分 ・ BPM 94-130 / 第二の山 🔥🔥
音楽的アプローチ ラテン・レゲトン・カリブ系で爆発させる第二の山。BPMは数字よりパーカッションの密度でテンションを作る。つなぎはメリハリ→スムース:1曲目で世界を切り替え、その後は流れで繋ぐ。
Gasolinaは94 BPMだけど体感は爆発的。ラテンは「遅く感じない」のが特徴。最後はBPM上げ気味で締める。
