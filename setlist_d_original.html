VERSION D

オリジナリティ版

ジャンル顔負けなし / ジャズ・ソウル・ファンク・レアグルーヴ・70s80s
このバージョンの設計思想:
普通のエアロでは絶対選ばれない、でも音楽として圧倒的に気持ちいい曲を組み合わせた版。
ジャズファンク・ディスコ・ソウル・アシッドジャズ・フレンチハウス・レアグルーヴを時代もジャンルも横断して配置。「音楽好きの講師ですね」が一発で伝わって、参加者の音楽体験そのものを更新できる。
狙い: 普通のジムでは聴けない選曲で差別化と知的好奇心を刺激。リピーター獲得・口コミ拡散しやすい。
各曲にジャンルタグ付き。
