90分レッスン セットリスト集

ステップ → エアロ → ステップ → ズンバ / 4種類のバージョン
使い方: その日の客層・雰囲気・気分で4種類のセットリストから選んでください。
各バージョンとも8段階構成(ゆっくり → かわいさ → たのしさ → はげしさ① → おちつき → セクシー → はげしさ② → クールダウン)で組まれていて、曲ごとにBPM・年・YouTubeリンク付き。
組み合わせて使うのもアリ:Aで王道、Cではげしさ①だけロックに差し替え、など。
VERSION A
王道版
→
30〜40代に確実に刺さる現代ヒット+00年代懐メロ。「これさえあれば外さない」安定の鉄板版。
鉄板 Bruno Mars Lady Gaga Beyoncé Shakira
VERSION B
美のイベント特化版
→
2025〜2026最新、K-POP×洋楽ミックス。ヘアセット・メイク等の美にまつわるイベントで「映える」「ステージ感」「トレンド共有」を最大化する全振り構成。
最新 BLACKPINK aespa ROSÉ & Bruno Mars Sabrina Carpenter Taylor Swift
VERSION C
ロック・ヘヴィ刺し版
→
はげしさ①と②にロック・メタル・パンクを集中投入。「無心で動くトランス感」を作る攻めの構成。リピーター獲得用。
攻め Linkin Park Foo Fighters Rage Against the Machine Green Day
